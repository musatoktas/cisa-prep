## How to review a question

For every question, wrong or right, write down:

1. Which word in the question decided the answer (*first*, *best*, *primary*...)
2. Why each wrong option is wrong, in one line
3. Which auditor rule it tests (see the main README: independence, risk first, evidence quality, preventive over detective)
